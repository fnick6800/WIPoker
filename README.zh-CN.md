# WIPoker · Android 单机扑克（可联网）

[English](README.md) · **简体中文**

[**下载 Android 安装包 →**](https://github.com/fnick6800/WIPoker/releases/latest) · [快速开始](#快速开始) · [问题与建议](https://github.com/fnick6800/WIPoker/issues)

**旅途中的一桌好牌，随时开局。**

WIPoker 是一个以**沉浸式单机对局**为核心、持续扩展的**扑克游戏基座**。目前支持德州扑克与掼蛋，后续会在统一的人物互动、牌桌体验与账户进度之上，继续加入其他扑克玩法。

安装后无需互联网，不用等待真人凑桌，即可与不同风格的电脑对手开局。牌与筹码的移动、人物反应、声音和对局节奏，共同营造真实围坐牌桌的氛围。

Android 7.0 及以上 · 离线单机 · 可选局域网联机 · 免费非营利分享

![没有网络，也有好牌局 / A great game. No internet needed.](images/01-offline.png)

## 快速开始

1. 打开[最新发布页](https://github.com/fnick6800/WIPoker/releases/latest)，展开 **Assets / 资源**，下载 `.apk` 安装包。
2. 在 Android 设备上安装，进入大厅选择**德州扑克**或**掼蛋**。
3. 离线与电脑对手游玩，或与朋友连接同一 Wi-Fi、手机热点后建桌加入。

**更新请直接覆盖安装，保留本地存档，不要先卸载。** 页面中的“Source code”压缩包是文档，不是游戏安装包。

## 先享受一个人的好牌局

飞机、旅途或没有外网的时候，也能与电脑对手完整游玩。牌局和进度保存在本地，可以随时继续自己的节奏。德州支持横竖屏，掼蛋采用竖屏牌桌与触摸理牌操作。

### 为什么做 WIPoker

我想在 Android 上有一个简单、轻松的单机扑克游戏：旅途中、飞机上，或者闲下来的一会儿，随时打开玩几局，不用联网，也不用等人凑桌。WIPoker 就是从这个愿望开始的。

这是一个出于兴趣制作、免费分享的非营利项目。希望让人安心享受打牌本身与真实的牌桌氛围，只使用虚拟筹码，没有真钱充值或提现。先照顾好一个人的休闲时光，想热闹时，也能和朋友一起玩。

## 一套牌桌体验，更多扑克玩法

WIPoker 的目标是逐步构建一个能承载多种扑克玩法的游戏基座。不同玩法延续熟悉的人物、牌桌互动和账户体验，同时保留各自的规则与节奏。

| 当前玩法 | 游戏体验 |
| --- | --- |
| **德州扑克** | 与电脑对手对局，支持横竖屏牌桌 |
| **掼蛋** | 四人搭档对局，电脑对手与队友，竖屏牌桌及触摸理牌 |

**后续计划加入更多扑克玩法。** 具体内容与时间以后续更新为准。

## 没有外网，也能一起玩

**旅途或机上，热点组局。** 连接同一手机热点或 Wi-Fi，无需互联网也能与身边朋友联机。热点需允许使用且设备互通。

| 场景 | 组局方式 |
| --- | --- |
| 一个人 | 纯离线与电脑对手游玩 |
| 朋友面对面 | 连接同一 Wi-Fi 或手机热点，在游戏内建桌、加入 |
| 远方好友 | 搭配 [MCTier](https://github.com/pmh1314520/MCTier) 等虚拟局域网工具 |

[MCTier 项目](https://github.com/pmh1314520/MCTier) · [下载工具](https://github.com/pmh1314520/MCTier/releases)。远程组网需要互联网与设备互通；普通上网代理不等于虚拟局域网，游戏当前不提供公共匹配大厅。

![没有外网，也能一起玩 / No internet. Still play together.](images/03-hotspot.png)

## 边玩边聊，更像围坐一桌

牌桌内发送文字、表情和 @ 称呼；长按说话、松开发送，上滑取消。每条语音消息最长 10 秒，支持可选音色和独立语音音量。

单人游玩还可按需开启牌型、预计胜率和思路提示，帮助熟悉牌面与决策。估算只使用自己的牌和公开信息，不读取其他玩家暗牌，也不是获胜保证；多人对局关闭学习辅助。

![边玩边聊，更像围坐一桌 / Play and chat. Feel at the same table.](images/04-chat.png)

## 使用细节

- 国际版支持简体中文与 English，在设置底部的 **Language / 语言** 中切换；人物录音保留原语言，玩家姓名与聊天不自动翻译。历史安装包的语言支持以各发布说明为准。
- 免费非营利分享，使用虚拟筹码，不涉及真钱充值或提现。
